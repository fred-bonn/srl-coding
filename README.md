# srl-coding

Spaced repetition learning for coding.

The goal is an application where a user starts a learning process and is
generated a coding challenge for a given topic/tag — for example "printing"
or "addition". Each topic has a static challenge that is always given when
the topic is first introduced. From then on, spaced repetition decides when
the topic is presented to the user again, in the form of a generated
challenge: either freshly generated, or fetched from the database of
existing challenges.
