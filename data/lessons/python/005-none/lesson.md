# None

`None` is a special value that represents the absence of a value.

Why would we want a value that means "nothing"?
Often a variable does not have a meaningful value yet: a result that will only be computed later, or something that simply is not there.
`None` is a way to say "there is no value here yet", instead of pretending that some ordinary value, like `0` or an empty string, is the real one.

## Example

We assign it to a variable and print it like any other value:

```python
nothing = None
print(nothing)
```

Output:

```
None
```
