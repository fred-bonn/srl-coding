# Integers

In the previous lesson on variables, we worked with *string variables*. In this lesson, we introduce *integer variables*.

An integer (`int`) is a whole number: positive, negative, or zero. You store one in a variable and print it the same way as a string.

Contrary to strings, integers (and other non-string types) are not declared using quotes. Enclosing an integer in quotes would turn it into a string.

## Example

```python
age = 21 # an integer
print(age)
year = "2026" # a string
print(year)
```

Output:

```
21
2026
```

Negative numbers work too:

```python
temperature = -12
print(temperature)
```

Output:

```
-12
```
