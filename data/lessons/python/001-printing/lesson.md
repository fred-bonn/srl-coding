# Printing in Python

Printing is how a program shows output to the user. In Python, you use the built-in `print` function. It takes one or more values and writes them to standard output, followed by a newline.

## Example

```python
print("Greetings")
print("Humans")
```

Output:

```
Greetings
Humans
```

## Submission

While working on your solution you can run your code as often as you like. Running executes your program and checks it against some of the lesson's tests, so you get feedback while you work. Runs cost nothing.

When you submit a solution to an assignment your code is checked against all of the lesson's tests, including tests that were withheld from your runs. Each test compares what your program actually did with what was expected. Afterward you get a report back, listing each test as passed or failed. For every failed test it also reports what the expected result was and what your code produced instead.

Running and submitting are not the same thing: running is practice, submitting is turning your homework in for grading. For these first lessons the difference is small, but as the lessons progress more of the tests are withheld until submission — so run as much as you need, and submit when you are confident in your solution.

For tests involving `print` the tests strive to be lenient so you do not have to produce the exact same output. For example, for this lesson, the test is checking if the uncapitalised words `hello` and `world` appear in the output in that order and ignores all punctuation.
