# Addition

Previously, we saw that `print` prints the value of an expression.
Expressions are not limited to variables and strings.
They can also be *arithmetic expressions*.
When we print an arithmetic expression, Python *evaluates* it first, and the value printed is the result of that evaluation.

## Example

The addition operator `+` evaluates to the sum of its two operands:

```python
print(2 + 3)
```

Output:

```
5
```

We can make arithmetic expressions using variables too:

```python
a = 2
b = 3
print(a + b)
```

Output:

```
5
```
